Configurando o Ambiente React Native

Um guia sequencial e didático para configurar o ambiente com Expo e criar o primeiro app mobile com Hello World.

🚀 Este guia usa o Expo — uma ferramenta que simplifica muito a configuração do React Native. Com ela, você não precisa instalar Android Studio nem Xcode para ver o app funcionando. Basta usar o celular!
Parte 1 Preparando o Computador
01
Instalar o Node.js
Requisito fundamental — igual ao React Web

Acesse nodejs.org e baixe a versão LTS. Se você já instalou para usar o React Web, pode pular este passo. Confirme no terminal:

terminal 
node -v
npm -v
02
Instalar o Visual Studio Code
Mesmo editor usado no React Web

Se você já tem o VSCode instalado do guia anterior, apenas adicione a extensão abaixo. Ela adiciona suporte a componentes React Native e autocomplete de componentes como <View> e <Text>.

📱
React Native Tools
Suporte oficial da Microsoft para RN
⚡
ES7+ React Snippets
Já instalado no guia anterior
03
Instalar o app Expo Go no celular
É com ele que você vai visualizar o app em tempo real

No celular (Android ou iPhone), baixe o app Expo Go diretamente na loja de aplicativos. É gratuito. Ele permite visualizar o seu app em desenvolvimento sem precisar gerar um arquivo instalável.

Parte 2 Criando o Primeiro Projeto
04
Criar o projeto com Expo
Comando que gera toda a estrutura do app

No terminal, execute o comando abaixo. Quando perguntado sobre o template, escolha Blank (o mais simples):

terminal 
npx create-expo-app meu-primeiro-rn --template blank
05
Entrar na pasta do projeto
Navegar até o diretório criado
terminal 
cd meu-primeiro-rn
06
Abrir no VSCode
Abrir a pasta do projeto no editor
terminal 
code .
07
Entender a estrutura de pastas
Conhecer os arquivos principais do projeto

A estrutura do Expo é mais simples que a do React Web. O arquivo principal é o App.js, na raiz do projeto:

estrutura do projeto 
meu-primeiro-rn/
├── App.js            ← componente principal (aqui você vai trabalhar)
├── package.json      ← configurações e dependências
├── app.json          ← configurações do app (nome, ícone, etc.)
└── assets/           ← imagens e fontes do app
08
Escrever o Hello, World!
Editar o componente principal — App.js

Abra o arquivo App.js e substitua todo o conteúdo pelo código abaixo. Perceba que no lugar de <div> usamos <View> e no lugar de <h1> usamos <Text>:

App.js 
import { View, Text } from 'react-native'

function App() {
  return (
    <View>
      <Text>Hello, World!</Text>
    </View>
  )
}

export default App
09
Rodar o servidor do Expo
Iniciar o projeto e gerar o QR Code

Execute o comando abaixo. Um QR Code vai aparecer no terminal ou no navegador. Escaneie com o celular usando o app Expo Go e o app será aberto diretamente no seu dispositivo!

terminal 
npx expo start
Parte 3 React Web vs React Native
📋
Comparação das tags equivalentes
O que muda na prática entre os dois

A lógica e os conceitos são os mesmos. O que muda é o vocabulário das tags:

React Web React Native Função
<div><View>Contêiner / agrupador
<h1>, <p>, <span><Text>Todo texto visível
<img><Image>Exibir imagens
<input><TextInput>Campo de texto
<button><TouchableOpacity>Botão clicável
<ul> / <li><FlatList>Listas de itens
CSS normalStyleSheet.create({})Estilização
⚠️ Importante!

Agora que o seu Hello World está funcionando no celular, observe que o código usa os mesmos conceitos que você já aprendeu no React Web.

🔹 View — É o equivalente à <div> do HTML. Serve como contêiner para organizar os elementos na tela. Todo conteúdo visível precisa estar dentro de uma <View>.

🔹 Text — No React Native, todo texto visível precisa estar dentro de um componente <Text>. Ao contrário do HTML, você não pode simplesmente escrever texto solto dentro de uma <View>.

🔹 import — Diferente do React Web onde as tags HTML já estão disponíveis, no React Native você precisa importar explicitamente cada componente que vai usar, como View e Text, diretamente da biblioteca 'react-native'.
