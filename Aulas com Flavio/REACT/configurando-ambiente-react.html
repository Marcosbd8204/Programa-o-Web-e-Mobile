Configurando o Ambiente React

Um guia sequencial e didático para configurar o ambiente e criar o primeiro projeto React do zero.

Parte 1 Preparando o Computador
01
Instalar o Node.js
Requisito fundamental para rodar o React

Acesse nodejs.org e baixe a versão LTS (Long Term Support). O Node.js é obrigatório porque o React e suas ferramentas rodam sobre ele. A instalação já inclui o npm, o gerenciador de pacotes. Após instalar, abra o terminal e confirme:

terminal 
node -v
npm -v
02
Instalar o Visual Studio Code
Editor de código recomendado

Acesse code.visualstudio.com e instale o VSCode. É gratuito, leve e tem excelente suporte ao React. Após instalar, adicione as seguintes extensões:

⚡
ES7+ React Snippets
Atalhos de código para React
✨
Prettier
Formatação automática do código
🔵
GitLens
Controle de versão visual (opcional)
03
Instalar o Git
Controle de versão — opcional, mas recomendado

Acesse git-scm.com e instale o Git. Será útil desde o início para salvar e versionar os projetos.

Parte 2 Criando o Primeiro Projeto
04
Criar o projeto com Vite
Ferramenta moderna e rápida para criar projetos React

O Vite é a forma recomendada atualmente para criar projetos React. É muito mais rápido que o antigo Create React App. No terminal, execute:

terminal 
npm create vite@latest meu-primeiro-react -- --template react
05
Entrar na pasta do projeto
Navegar pelo terminal até o diretório criado
terminal 
cd meu-primeiro-react
06
Instalar as dependências
Baixar todos os pacotes necessários

Este comando baixa tudo que o projeto precisa para funcionar. Uma pasta chamada node_modules será criada com todas as bibliotecas.

terminal 
npm install
07
Abrir no VSCode
Abrir a pasta do projeto direto pelo terminal
terminal 
code .
08
Entender a estrutura de pastas
Conhecer os arquivos principais do projeto

Estrutura gerada pelo Vite e para que serve cada arquivo:

estrutura do projeto 
meu-primeiro-react/
├── src/
│   ├── App.jsx       ← componente principal
│   └── main.jsx      ← ponto de entrada da aplicação
├── index.html        ← HTML base da aplicação
└── package.json      ← configurações e dependências
09
Escrever o Hello, World!
Editar o componente principal — src/App.jsx

Abra o arquivo src/App.jsx e substitua todo o conteúdo pelo código abaixo:

src/App.jsx 
function App() {
  return (
    <h1>Hello, World!</h1>
  )
}

export default App
10
Rodar o servidor de desenvolvimento
Ver o resultado no navegador

Execute o comando abaixo. O terminal exibirá um endereço como http://localhost:5173. Abra-o no navegador e o Hello, World! estará na tela!

terminal 
npm run dev
⚠️ Importante!

Agora que o seu Hello World está funcionando, observe que o código que você escreveu já utiliza três conceitos fundamentais do React que você vai aprender com mais profundidade nas próximas aulas:


🔹 Componente — A função App que você criou é um componente. No React, tudo é construído com componentes: são como "peças" reutilizáveis da sua interface. Cada componente é responsável por uma parte da tela.


🔹 JSX — O código que parece HTML dentro da função (<h1>Hello, World!</h1>) não é HTML de verdade — é JSX. É uma sintaxe especial que permite escrever estruturas visuais dentro do JavaScript de forma mais legível. Por baixo dos panos, o Vite transforma esse JSX em JavaScript puro.


🔹 export default — Essa linha no final do arquivo torna o componente App disponível para ser usado em outros arquivos do projeto. No React, os componentes precisam ser exportados para que possam ser importados e utilizados em outros lugares da aplicação.
